External Signature Control Surface

A modern control panel for passkey-backed execution on Solana devnet: initialize identity, run wrapped instructions, manage sessions, and test execution-account transfers in one place.

External Account

The passkey-derived account that stores WebAuthn identity and authorizes wrapped execution.

Execution Account

Program-derived PDA used as signer for CPI in ExecutionAccount mode (e.g. system transfers).
